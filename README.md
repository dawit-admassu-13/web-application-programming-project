# Web Application Programming Project

> 📚 **Learning project** — front-end pages and exercises from web application
> programming course labs, built with plain HTML, CSS, and JavaScript.

**Live site:** https://dawit-admassu-13.github.io/web-application-programming-project/

## Contents

| File / folder | Description |
|---|---|
| `index.html` | Landing page linking to the daily pages and exercises |
| `aboutme.html` | "About me" page styled with an external stylesheet (`styles/styleme.css`) |
| `Registration.html` | Workshop registration form with required fields, dropdowns, and payment options (`RegistrationStyle.css`) |
| `Lab3/` | Multi-section storefront landing page: navigation bar, hero section, image gallery, and footer link columns (`style2.css`) |
| `Lab5/` | JavaScript exercises using `filter` and `reduce` on arrays |

## Tech Stack

HTML5 · CSS3 · JavaScript (ES6)

## Running

No build step — open `index.html` in a browser, or visit the live site above.
